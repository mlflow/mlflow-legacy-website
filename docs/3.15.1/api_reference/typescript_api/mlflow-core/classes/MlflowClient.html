      Upload OTel spans to a Databricks Unity Catalog location via the OTLP HTTP+protobuf endpoint. The spansTableName is the fully qualified spans table (catalog.schema.table) and is forwarded as the X-Databricks-UC-Table-Name header used by Databricks to route the payload to the correct UC location.

      Uses @opentelemetry/exporter-trace-otlp-proto which serializes the spans to the OTLP ExportTraceServiceRequest protobuf wire format — the Databricks endpoint only accepts application/x-protobuf, not the OTLP/HTTP+JSON form.

    searchTraces

    • searchTraces(options: SearchTracesOptions): Promise<SearchTracesResult>

      Search for traces that match the given search criteria. Corresponding to the Python SDK's search_traces() method.

      By default the span data of each matching trace is fetched with one download per trace; traces whose span data cannot be downloaded are skipped, matching the Python SDK's behavior. Pass includeSpans: false to return trace metadata only, with empty span data.

      Locations are passed through to the tracking server, which validates that it supports the requested location types.

      Parameters

      • options: SearchTracesOptions
        • Optionalfilter?: string

          Search filter string, e.g. "tags.env = 'prod'".

        • OptionalincludeSpans?: boolean

          Whether to fetch span data for each matching trace. Defaults to true. When false, only trace metadata is returned and the traces have empty span data.

        • locations: TraceLocation[]

          Trace locations (e.g. MLflow experiments) to search over.

        • OptionalmaxResults?: number

          Maximum number of traces to return in a single page.

        • OptionalorderBy?: string[]

          List of order-by clauses, e.g. ['timestamp_ms DESC'].

        • OptionalpageToken?: string

          Pagination token obtained from a previous searchTraces call.

      Returns Promise<SearchTracesResult>

      The matching traces and, when more results are available, a token for the next page.

      Example

      const { traces, nextPageToken } = await client.searchTraces({
        locations: [
          { type: TraceLocationType.MLFLOW_EXPERIMENT, mlflowExperiment: { experimentId: '123' } },
        ],
        filter: "tags.env = 'prod'",
        maxResults: 10,
        orderBy: ['timestamp_ms DESC'],
      });
